# Feature: Project-details

## Goal

implement `project-details.html`

## Designs

![target layout](../../assets/672103614_988797986917221_845717055040735271_n.jpg)

## Work

- Create a detailed page for each project
- Display the project title in middle
- Show a screenshot or preview image of the project
- Include a description explaining:
  - what the project does
  - what technologies were used
- Buttons should change color on hover
- Images should resize properly on smaller screens
- Text should remain easy to read on desktop and mobile devices
- Images should resize correctly on smaller screens

## Deliverables

- Project detail page loads correctly
- Hover effects work on buttons
- Content is organized clearly
- Layout is responsive on desktop and mobile
- Layout remains responsive on smaller screens
- No overlapping text or broken spacing
- HTML uses semantic structure for accessibility

## implementation

Features added:

- Created separate detailed pages for each project
- Added project titles, descriptions, and preview images
- Included technologies used for each project
- Added hover effects for buttons and links
- Implemented mobile-first responsive layouts
- Added tablet and desktop media query support
- Ensured images resize correctly on smaller screens
- Improved text readability across devices
- Used semantic HTML elements for accessibility
- Organized content into clear sections
- Prevented overlapping content and broken spacing

Projects implemented:

- Pac-Man Console Game
- Trash Sorting AI
