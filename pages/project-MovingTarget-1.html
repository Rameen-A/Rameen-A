Moving Target Arcade Game

This project is a console-based arcade game built in C#. The player controls an X character using arrow keys and must catch moving targets before the timer ends. As the player scores points, the targets move faster, increasing the difficulty and creating a more challenging experience.

Main Challenges

Handling multiple moving targets while keeping gameplay responsive and maintaining smooth collision detection.

Key Learnings

Improved my understanding of game loops, timers, keyboard input, and collision detection in C#.
